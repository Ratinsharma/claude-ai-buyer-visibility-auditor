# Contributing

Thanks for improving this skill.

## How to contribute

1. Fork the repo and create a branch from `main`.
2. Keep changes focused on `SKILL.md` / docs — no invented APIs or fake claims in audit logic.
3. Test the skill flow in Claude Code: install, run **Audit our AI visibility**, confirm scoring + `llms.txt` output.
4. Open a PR with a clear description of what changed and why.

## Guidelines

- Prefer clarity over cleverness in `SKILL.md`.
- Never instruct the model to fabricate proof points.
- Keep install URLs pointed at `Ratinsharma/claude-ai-buyer-visibility-auditor`.

## Issues

Use GitHub Issues for bugs and feature ideas. Include Claude Code / Claude.ai version when relevant.
